# TrustLens - Seller Trust & Behavior Analytics Dashboard

TrustLens is an interactive Seller Trust & Behavior Analytics UX dashboard designed to monitor merchant credibility, assess risk, track behavioral signals, and take governance actions.

## 🚀 Features

- **1. Executive Trust Overview**: High-level risk score distribution, return pressure, customer sentiment health, and active anomaly alerts.
- **2. Trust vs. Behavior Signals**: Correlate return rate spikes, negative review sentiment, and response time delays with long-term trust score degradation.
- **3. Seller Performance Scorecard**: Granular seller-level deep dive tracking fulfillment integrity, dispute rates, return abuse indicators, and rating decay.
- **4. Seller Behavior Segmentation**: Actionable clustering across Risk-Prone, Inconsistent Logistics, Dispute-Heavy, and Top-Tier merchant cohorts.
- **5. Trust-Risk Governance Actions**: Transparent, evidence-backed decision support for early coaching, payout withholdings, probation, and suspension.
- **Integrated UX Rationale & Annotations**: Interactive toggleable design rationale annotations explaining UX decisions.

## 🛠️ Tech Stack

- **HTML5 & Vanilla JavaScript**
- **Tailwind CSS (via CDN)**
- **Google Material Symbols & Google Fonts (Inter, JetBrains Mono)**
